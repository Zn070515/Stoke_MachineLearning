## 第一批：再次正式训练前（研究正确性）— 4 个 formal-OOS blockers

### T1 — Formal PanelStore 外部 artifact hard-gate（§四）
- **范围**：`panel_store.py` 给 `_validate_meta` / `load_panel_memmap` 加 `strict_external_meta: bool = False`。`strict_external_meta=True`（formal 默认）时 `_WARN_META_KEYS` 5 项全部 hard-fail，且「rec/exp 任一 None」也失败（audit：stored=None current=hash 不能用「缺一个就不比较」放行）。explore 模式保持现状 warning + None-skip。
- **调用点**：`train_panel.py` formal 模式（`_formal_mode`）传 `strict_external_meta=True`；explore / `--no-formal` 传 False。
- **验证**：篡改 store 的 pytest——formal 下篡改 membership_hash、或单向缺键 → refuse；explore 下 → warning proceed。现有测试不破（默认 False）。
- **风险**：Med（formal 默认开会让已有旧 store 被拒——这是预期；保留 explore 逃生口）。

### T2 — CSI membership out_date 半开区间 + download_index_hist data_dir（§五/§七）
- **范围**：`download_index_hist.py:112-117` `rebuild_membership` 把 `out_date` 从「最后一次 present snapshot」（`rg["query_date"].max()`）改成「第一个 absent snapshot」。spell 内月份连续（`new_run` 按 `month_ids.diff().gt(1)` 切分），故最后一个 present 月的下一个月初就是第一个 absent：`out_date = rg["query_date"].max() + pd.DateOffset(months=1)`，`still_active = out_date >= last_grid` 语义不变（grid 末尾仍 present → NaT）。
- **§七**：`:199` 补 `data_dir = cfg.project.data_dir`；`:198-206` 的 `except Exception` 改为 manifest 写失败 → 任务非成功（exit 非 0），不再静默吞；`failed_snapshots` 非空时脚本本就该非成功（当前只 print）。
- **验证**：合成 spell 测试——1/2 月 present、3 月 absent → out_date=3 月初（半开区间 `[in, out)` 仍含 2 月）；grid 末尾 present → NaT。manifest 写失败 → 非 0 exit。
- **风险**：Low。

### T3 — Calendar content hash 绑定 + 显式贯穿（§八/§九）
- **Part A（§八）**：`train_panel_gates.py:238` 之后补：`report.get("calendar_artifact_hash")` vs 当前 data_dir 的 calendar artifact hash（复用 gate 报告的 hash 口径）→ mismatch 进 problems → gate fail。这让「周一 gate → 周二改 calendar → 周三直接训练」被拒绝。
- **Part B（§九）**：消除 5 个 `get_research_calendar(strict=True)` 无 data_dir 旁路：`preprocess_new_data.py:257`、`train_panel_gates.py:352`、`fit_topic_model.py:71/167`、`train_panel_panel.py:473`、`features/panel_helpers.py:29`。统一从入口显式传 data_dir / ResearchContext.calendar。`fit_topic_model.py` 尤其要保证 `_calendar_hash()` 与 PIT 映射用**同一个** calendar 实例。
- **验证**：改 exchange_calendar.parquet 内容（不动 CALENDAR_VERSION）→ gate fail；断言 5 个调用点收到显式 data_dir。
- **依赖**：先于 T4（同文件 `train_panel_gates.py`，串行）。
- **风险**：Med（Part B 跨文件 threading 重构）。

### T4 — Channel coverage 契约语义统一（§十一）
- **范围**：`feature_profile.py` 把单一 `minimum_coverage: dict[str, float]` 扩展为 per-channel coverage contract：每个 required channel 声明 `(metric, threshold)`，metric ∈ {stock_coverage, cell_coverage, date_coverage, valid_state_cell_coverage}。live 路径（stock-level）与 prebuilt 路径（cell-level）各自按声明 metric 计算。
- **formal unprobeable → fail**：`train_panel_gates.py:164-168` 的 warning 路径在 formal 下改 abort——required channel 无法 probe（prebuilt 无 has_* flag）必须失败。这要求 headline_v1 的 required channels 在 prebuilt 模式也能 probe（补 has_* 或显式 coverage manifest）。
- **PanelStore 保存 `channel_coverage_manifest`**：构建时写入，重放直接读。
- **验证**：prebuilt 缺某 required channel probe → formal abort / explore warn；stock vs cell 各自的契约矩阵 pytest。
- **依赖**：T3（同文件串行）。
- **风险**：Med（语义收紧，prebuilt 模式 required 全改 fail）。
